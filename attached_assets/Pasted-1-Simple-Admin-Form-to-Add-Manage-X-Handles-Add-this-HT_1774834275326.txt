1. Simple Admin Form to Add / Manage X Handles
Add this HTML to a new admin page (e.g., /admin/x-handles or wherever your admin section lives). It’s clean, easy to use, and saves the list of handles (without the @ symbol).
HTML<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Manage X Handles for Emmett Echo</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 800px; margin: 40px auto; }
    textarea { width: 100%; height: 200px; font-family: monospace; }
    button { padding: 12px 20px; font-size: 16px; margin-top: 10px; }
    .status { margin-top: 15px; font-weight: bold; }
  </style>
</head>
<body>
  <h1>Manage Monitored X Handles</h1>
  <p>Enter one X handle per line (without the @ symbol). These will be used to pull the latest 24 hours of posts.</p>
  
  <textarea id="handlesInput" placeholder="realDonaldTrump
GOP
heritage
smallbizvoices
AmericaFirstLegal"></textarea>
  
  <button onclick="saveHandles()">Save X Handles</button>
  
  <div id="status" class="status"></div>

  <script>
    // Load existing handles when page loads (optional)
    window.onload = () => {
      fetch('/api/get-x-handles')
        .then(r => r.json())
        .then(data => {
          if (data.handles) {
            document.getElementById('handlesInput').value = data.handles.join('\n');
          }
        });
    };

    function saveHandles() {
      const text = document.getElementById('handlesInput').value.trim();
      const handles = text.split('\n')
        .map(h => h.trim().replace('@', ''))
        .filter(h => h.length > 0);

      fetch('/api/save-x-handles', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ handles: handles })
      })
      .then(res => res.json())
      .then(data => {
        document.getElementById('status').innerHTML = 
          `✅ Saved ${handles.length} handles: ${handles.join(', ')}`;
      })
      .catch(err => {
        document.getElementById('status').innerHTML = `❌ Error: ${err}`;
      });
    }
  </script>
</body>
</html>
2. Backend Routes (Flask-style example)
Add these two simple routes to your Python backend:
Pythonfrom flask import Flask, request, jsonify
import json
import os

app = Flask(__name__)

# Simple file-based storage (replace with your DB later)
HANDLES_FILE = 'x_handles.json'

def load_handles():
    if os.path.exists(HANDLES_FILE):
        with open(HANDLES_FILE, 'r') as f:
            return json.load(f).get('handles', [])
    return []

def save_handles(handles):
    with open(HANDLES_FILE, 'w') as f:
        json.dump({'handles': handles}, f)

@app.route('/api/save-x-handles', methods=['POST'])
def save_x_handles():
    data = request.get_json()
    handles = data.get('handles', [])
    save_handles(handles)
    return jsonify({"status": "success", "handles": handles})

@app.route('/api/get-x-handles', methods=['GET'])
def get_x_handles():
    handles = load_handles()
    return jsonify({"handles": handles})
This gives you a working form + backend storage right away.
